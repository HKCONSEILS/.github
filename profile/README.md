# HK CONSEILS

**Intelligence artificielle générative souveraine, hébergée chez vous.**

Nous concevons et exploitons des plateformes d'IA générative **on-premise** pour les PME et les ETI : vos modèles, vos données et vos traitements restent sur votre infrastructure, sans dépendance à un fournisseur cloud tiers.

Basés à **Saint-Priest, métropole de Lyon** — [hkconseils.fr](https://hkconseils.fr)
